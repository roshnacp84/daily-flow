# Daily Flow 📱✨

A modern, fast, mobile-first **Daily Planner** with priority checklists, smart categorization, and zero-setup offline storage. Built with **Next.js 16 (Turbopack)**, **Tailwind CSS 4**, and **shadcn/ui**.

Live Deployment: [https://snappy-walnut-xv4mukl.tmp.now](https://snappy-walnut-xv4mukl.tmp.now)

---

## 🚀 Features

- **📱 Mobile-First UX (PWA)**: Designed specifically for thumb navigation on mobile phones with touch-friendly tap targets, safe-area offsets, and web app manifest support for home screen installation.
- **⚡ Prioritized Checklists**: Tasks with clear priority badges (**Urgent**, **High**, **Medium**, **Low**), smart sorting, and visual color indicators.
- **🏷️ Categorization**: Filter tasks by **Work**, **Personal**, **Urgent**, **Health**, and **Errands** with live counts.
- **📅 Week & Day Scroller**: Interactive horizontal day switcher to review past days, organize today, or plan upcoming days.
- **📊 Daily Progress & "Move to Tomorrow"**: Live completion percentage progress bar with motivational feedback and a 1-tap button to forward pending tasks to tomorrow.
- **🔐 User Authentication**: In-app sign-in flow supporting **GitHub**, **Google**, **Email/Password**, and **Guest Explorer** modes.
- **💾 Offline-Ready LocalStorage**: Instant task sync and zero latency—no database configuration required.
- **🌓 Dark & Light Modes**: Seamless theme switching with system detection.

## 🏃 Getting Started

### 1. Clone & Install

```bash
git clone https://github.com/roshnacp84/daily-flow.git
cd daily-flow
npm install
```

### 2. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) on your computer, or access it from your phone on the same Wi-Fi using your local network IP (e.g. `http://<your-local-ip>:3000`).
